# Credits

## Camera product photography

The images in `packages/frontend/public/camera-images/` are **product photographs owned by
Axis Communications AB**, retrieved from the public product pages on <https://www.axis.com>.

They are included so this demo — built as a code test _for Axis_ — shows recognisable
hardware instead of placeholder boxes. They are committed to the repository rather than
hotlinked so the app and its end-to-end test run offline and stay deterministic.
